# ⚙️ Full-Stack MES & 3D Digital Twin Simulation System
> An Integrated Industrial Telemetry & Real-time Monitoring platform
> Developed by, Yunpeng Gao

-----
#Project Overview
this project is a full stack **Digital twin and Manufacturing Execution System(MES),It bridges the gap between physical-visual simulation and data-driven management screens.
The system consists of a modern, Cyberpunk-themed Web Dashboard, a centralized Node.js event broker, and a windowed 3D production line simulation client built in Unity.

---The workpiece life-cycle
1. Oder Dispatch   -> Web Input (Manual) OR Unity Trigger (Auto).
2. Machining Station --> State changes from Pending ➔ Processing ➔ Completed(Manual OR Unity Trigger).
3. Assembly Station  --> Component mating & assembly verification tracking(Manual OR Unity Trigger).
4. Dashboard KPI -->>Live re-calculation of First Pass Yield (FPY)% / Scrap Log.
